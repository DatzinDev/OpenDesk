### Ningún cliente se queda sin respuesta.

La mesa de ayuda gratuita y de código abierto que asigna cada solicitud, cuida los tiempos de respuesta
y te dice qué tan satisfechos quedan tus clientes.

[**Pruébalo en 5 minutos**](docs/instalacion.md) · [Novedades](CHANGELOG.md)

![Versión](https://img.shields.io/badge/versi%C3%B3n-0.1.3-ff8e3c)

![Gratis](https://img.shields.io/badge/costo%20por%20usuario-%240-0b1d3a)

</div>

---

- **Cada solicitud tiene dueño.** Se registra en segundos y se asigna a la persona correcta.
- **Cada avance se aprueba.** Fechas, escalamientos y cierres pasan por el Gestor.
- **Los tiempos se cuidan solos.** Avisos antes de vencer y escalamiento automático si nadie responde.
- **El cliente califica con un clic.** Encuesta de satisfacción al cerrar.
- **Sabes cómo vas sin armar reportes.** Seis tableros de analítica y exportación a Excel.

Sin costo por usuario, en tu propio servidor y con acceso por Google.

```bash
git clone https://github.com/DatzinDev/OpenDesk.git && cd OpenDesk
cp .env.example .env && docker compose up -d --build
```
